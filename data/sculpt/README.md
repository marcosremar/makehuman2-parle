# Torso relief

`male-torso-relief.npz` is a low resolution map of muscle relief, taken from a sculpture
(`Sculpt.fbx`) that the project owner cleared for use in the Parle game on 5 November 2026.

Unlike the rest of `data/`, this file is **not CC0**, and that clearance does not extend to other
projects. The sculpture itself is not in this repository: keep it in `.local/sculpt/`.
